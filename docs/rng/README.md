# Модуль RNG (Генераторы псевдослучайных чисел и распределений)

> Ответственный: Шаимов Богдан  
> Состояние: разработан в ветке `feat/RNG-001-M1-protocols` (v2.0.1), проверен модульными тестами  
> База для слияния: `dev` | Обновлено: `2026-11-15`

## 1. Назначение

Модуль `RNG` отвечает за генерацию псевдослучайных последовательностей и случайных величин с заданными распределениями для симулятора планировщика беспроводной сети (`PyScheduler`). Модуль поддерживает работу с независимыми потоками (`stream_idx` / `stream_offset`), централизованным реестром потоков `StreamAllocator` по ключу `(domain, purpose, entity_id)` и независимыми прогонами (`run_idx`), что обеспечивает строгую повторяемость экспериментов. Математическая генерация изолирована от остального кода симулятора статическими протоколами (`typing.Protocol`).

## 2. Границы ответственности

**Делает:**
- Задаёт статические контракты (`typing.Protocol`): внутренний `UniformEngine` (для математических ядер) и внешний `RandomProvider` (фасад распределений для моделей).
- Генерирует детерминированные числа на строгом полуинтервале $[0.0, 1.0)$ с помощью двух стратегий:
  - `RngStream` (`MRG32k3a`): независимая Python-реализация по статье P. L'Ecuyer et al. (2002), побитово совместимая с `ns-3`.
  - `PhiloxStream` (`Philox4x64`): 64-битный counter-based генератор (10 раундов) с нормализацией по стандарту IEEE-754 (через битовый сдвиг мантиссы).
- Предоставляет фасад `RandomGenerator` для извлечения случайных величин: равномерного (`uniform`), нормального (`normal`, метод Бокса — Мюллера с кэшированием), экспоненциального (`exponential`) и дискретного равновероятного (`get_integer`) распределений.
- Предоставляет реестр `StreamAllocator` для бесколлизионной выдачи `stream_idx` и провайдеров по кортежу `(domain, purpose, entity_id)`.
- Выполняет строгую валидацию входных параметров: запрет `bool`, `NaN`, `±Inf`, контроль верхних границ `seed <= 4294944442`, `stream_idx <= 2^63 - 1`, `run_idx <= 2^63 - 1`, а также защиту от бесконечного цикла при `bound == 0.0` и `variance > 0.0`.

**Не делает:**
- **Не считывает данные из файлов.** Механика предзаписанных трасс (`DataStream`) исключена из модуля для проектирования в рамках отдельной будущей фичи `FEAT-RNG-003`.
- Не рассчитывает физику движения абонентов, состояние радиоканала и сетевой трафик (это задача соответствующих моделей, которым генератор передаётся через Dependency Injection).

## 3. Входы, выходы и зависимости

| Вход | Откуда | Формат / смысл |
|---|---|---|
| `seed` | Вызывающий модуль / ядро | `int` в диапазоне `[0, 4294944442]` (`0` заменяется на `12345`; строго `< m2 = 4294944443`). Запрещены отрицательные числа и `bool`. |
| `base_stream_idx` / `stream_idx` | `StreamAllocator` / ядро | `int` в диапазоне `[0, 2^63 - 1]` — базовый индекс потока. |
| `stream_offset` | Модели симулятора | `int` в диапазоне `[0, 2^63 - 1]` — смещение подпотока (`base_stream_idx + stream_offset <= 2^63 - 1`). |
| `run_idx` | Вызывающий модуль / ядро | `int` в диапазоне `[1, 2^63 - 1]` — номер независимого прогона симуляции. |
| `engine` | Вызывающий модуль / ядро | `str` (`'MRG32k3a'`, `'Philox'`) — выбор математической стратегии. |
| `(domain, purpose, entity_id)` | `SimulationManager` | Ключ регистрации уникального потока в `StreamAllocator` (например, `('CHANNEL', 'SHADOW_FADING', 17)`). |
| Параметры распределений | Модели симулятора | `min_val`, `max_val`, `mean`, `variance`, `bound` (строгая фильтрация `NaN`/`Inf` и невалидных границ). |

| Выход | Куда | Формат / смысл |
|---|---|---|
| Базовое число $U(0, 1)$ | `RandomGenerator` | `float` строго в диапазоне $[0.0, 1.0)$ из методов `rand_u01()`. |
| Случайная величина | Модели симулятора | `float` (`uniform`, `normal`, `exponential`) или `int` (`get_integer`). |

**Зависимости:**
- Только встроенная библиотека Python 3.12 (`math`, `typing`). Внешних зависимостей от других модулей проекта нет.

## 4. Как проверить работу

Модуль запускается и верифицируется автономно локальными модульными тестами из корня проекта:

```bash
pytest test_rng.py -v
```

Тесты проверяют совпадение MRG32k3a с эталоном ns-3, математические границы Philox4x64, отсутствие коллизий между потоками, равномерность get_integer на отрицательных границах, отбраковку NaN/Inf, защиту от зависания при bound=0.0, верхние границы seed/stream_idx/run_idx и работу StreamAllocator.

## 5. Основные компоненты

| Компонент / Файл `RNG.py` | Назначение                                                                                                     | Где используется |
|---|----------------------------------------------------------------------------------------------------------------|---|
| `UniformEngine` (`Protocol`) | Статический контракт ядра генерации ПСЧ с методом `rand_u01()`.                                                | Для проверки соответствия стратегий внутри `RandomGenerator`. |
| `RandomProvider` (`Protocol`) | Статический контракт источника распределений (4 метода).                                                       | Как аннотация типа в моделях `Mobility`, `Channel`, `Traffic` (DI). |
| `RngStream` | Стратегия `MRG32k3a` с предвычислением матриц перехода для сдвига по потокам и прогонам.                       | В `RandomGenerator` (по умолчанию `engine='MRG32k3a'`). |
| `PhiloxStream` | Стратегия `Philox4x64` (10 раундов, буфер на 4 числа, нормализация IEEE-754 мантиссы).                         | В `RandomGenerator` при `engine='Philox'`. |
| `RandomGenerator` | Фасад генерации случайных величин. Управляет словарём кэшированных потоков `_streams` по стратегии `_ENGINES`. | Единая точка конфигурации в `SimulationManager` и внедрения в модели. |
| `StreamAllocator` | Реестр и аллокатор потоков по ключу `(domain, purpose, entity_id)`.                                              | В `SimulationManager` для выдачи изолированных генераторов подсистемам.|

## 6. Один типичный сценарий

**Сценарий: Выделение потока через StreamAllocator и генерация нормальной величины**
1. Ядро симулятора создаёт `allocator = StreamAllocator(seed=12345, run_idx=1, engine='MRG32k3a')`.
2. Для модели затенения канала абонента UE 17 запрашивается провайдер:`rng = allocator.get_provider("CHANNEL", "SHADOW_FADING", entity_id=17)`. Аллокатор регистрирует тройку `('CHANNEL', 'SHADOW_FADING', 17)` за уникальным индексом `stream_idx = 0` и возвращает `RandomGenerator`.
3. Модель вызывает rng.normal `(mean=0.0, variance=64.0, bound=24.0)`.
4. Метод `normal()` проверяет параметры на отсутствие `NaN/Inf`, убеждается, что `variance >= 0 и bound > 0`, инициализирует поток `RngStream`, генерирует пару чисел по методу Бокса — Мюллера, сохраняет второе число в `_normal_cache` и возвращает первое.

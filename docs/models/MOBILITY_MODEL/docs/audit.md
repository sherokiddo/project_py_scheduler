### AUD-MOB-001 — MapBorders.__new__
- **Объект:** `PyScheduler/MOBILITY_MODEL.py::MapBorders.__new__`.
- **Категория:** подтверждённый баг.

- **Влияние:** Затрагивает описанную ветвь; масштаб зависит от выбранной модели, входных данных и жизненного цикла.
- **Как проверить:** После reset создать карту (0,100,0,100), затем запросить другие границы; отдельно передать x_min=0,x_max=None. Проверить документированную политику singleton и явную ошибку валидации вместо случайного TypeError.

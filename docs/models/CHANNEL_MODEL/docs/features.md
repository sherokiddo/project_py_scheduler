# План развития модуля CHANNEL_MODEL

> Ответственный: Кутенков Андрей | Обновлено: 2026-10-17

Идентификаторы глобально уникальны: `FEAT-CHN-NNN`. Прежний локальный FEAT-001..004 соответствует FEAT-CHN-001..004; порядковые номера и смысл предложений сохранены. Общая крупная фича — `FEAT-INT-001`, спецификация [INT-MF-001 v1.0](../../integration_report.md). Все интерфейсы в ней — проектные.

## 1. Предложения для своего модуля

### FEAT-CHN-001 — Разделить статическую конфигурацию и динамическое состояние UE
- **Статус:** идея; черновик уточнён по коду, согласование изменений не получено.
- **Проблема сейчас:** LOS/SF/O2I — словари класса с ключом только UE_ID, что не изолирует одну UE у разных BS. TDL отдельно хранит ues_info.
- **Цель:** Разделить параметры BS/сценария и состояние по (ue_id,bs_id); адаптер выдаёт ChannelResult с явным временем.
- **Предлагаемое изменение:** Разделить параметры BS/сценария и состояние по (ue_id,bs_id); адаптер выдаёт ChannelResult с явным временем.
- **Входит / не входит:** собственный адаптер, внутреннее состояние и тесты CHANNEL_MODEL; изменения SimulationManager, RNG и UE_MODULE выполняют их владельцы. Переписывание математических формул не входит.
- **Входы и выходы:** черновик INT-MF-001, разделы 3–6; адаптер принимает StepContext и снимок UE, выдаёт результат своего модуля. Для file вход — готовые записи; для model — параметры и выделенный RNG.
- **Зависимости:** SimulationManager — время и маршрутизация; UE_MODULE — ID и применение; RNG — воспроизводимые потоки. Запросы перечислены ниже в разделе 2 настоящего файла.
- **Шаги:** 1) использовать выполненную сверку исходников и результаты audit; 2) согласовать соответствующую часть INT-MF-001; 3) реализовать собственный адаптер/изменение; 4) выполнить проверку ниже и общую интеграционную матрицу.
- **Проверка готовности:** Один UE у двух BS имеет независимые LOS/SF/O2I; очистка одной радиолинии не затрагивает другую.
- **Риски и вопросы:** действующие сигнатуры проверены; до изменения сохранить поведение базового сценария и согласовать правила времени, RNG и lifecycle.
- **Ссылки:** [спецификация](../../integration_report.md), [ревизия](audit.md).

- **Проблема сейчас:** Готовый SINR сейчас не импортируется. UE.UPD_CH_QUALITY вызывает модель и содержит собственные случайные ветви высоты; file-режим должен обходить и их.
- **Цель:** ChannelFileAdapter возвращает только профиль sinr-v1; скаляр и массив RB не смешиваются. LOS/PL/SF не достраиваются математикой.
- **Предлагаемое изменение:** ChannelFileAdapter возвращает только профиль sinr-v1; скаляр и массив RB не смешиваются. LOS/PL/SF не достраиваются математикой.

- **Шаги:** 1) использовать выполненную сверку исходников и результаты audit; 2) согласовать соответствующую часть INT-MF-001; 3) реализовать собственный адаптер/изменение; 4) выполнить проверку ниже и общую интеграционную матрицу.

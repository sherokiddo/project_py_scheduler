# drl

Этот пакет выделен под интеграцию DRL-планировщиков в PyScheduler.

Зачем он нужен:
- `SimulationManager` остается ядром оркестрации
- симулятор не переписывается в RL-фреймворк
- вся DRL-специфичная логика живет в одном изолированном месте

Что должно находиться здесь:
- контракты simulation bridge
- observation builder
- action adapter
- DRL-aware реализации scheduler-ов
- скрипты обучения и оценки
- утилиты для parity-метрик
- инструменты анимации и экспорта для DRL-экспериментов

Текущий этап:
- пакет пока фиксирует только bridge-контракт
- runtime-интеграция еще не подключена

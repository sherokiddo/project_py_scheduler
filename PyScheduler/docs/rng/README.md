# Модуль RNG (Генераторы псевдослучайных чисел и распределений)

> Ответственный: Шаимов Богдан  
> Состояние: разработан в ветке `feat/RNG-001-M1-protocols` (v2.0.0), проверен модульными тестами  
> База для слияния: `dev` | Обновлено: `2026-11-06`

## 1. Назначение

Модуль `RNG` отвечает за генерацию псевдослучайных последовательностей и случайных величин с заданными распределениями для симулятора планировщика беспроводной сети (PyScheduler). Модуль поддерживает работу с независимыми потоками (`stream_idx` / `stream_offset`) и прогонами (`run_idx`), что обеспечивает строгую побитовую повторяемость экспериментов. Математическая генерация изолирована от остального кода симулятора статическими протоколами, что позволяет избежать жёсткого связывания компонентов.

## 2. Границы ответственности

**Делает:**
- Задаёт статические контракты (`typing.Protocol`): внутренний `UniformEngine` (для математических ядер) и внешний `RandomProvider` (фасад распределений для моделей).
- Генерирует детерминированные числа на строгом полуинтервале $[0.0, 1.0)$ с помощью двух стратегий:
  - `RngStream` (`MRG32k3a`): матричный алгоритм, побитово свалидирован с эталоном из симулятора `ns-3`.
  - `PhiloxStream` (`Philox4x64`): 64-битный counter-based генератор (10 раундов шифрования) с нормализацией по стандарту IEEE-754 (через битовый сдвиг мантиссы).
- Предоставляет фасад `RandomGenerator` для извлечения случайных величин: равномерного (`uniform`), нормального (`normal`, метод Бокса — Мюллера с кэшированием), экспоненциального (`exponential`) и дискретного равновероятного (`get_integer`) распределений.
- Управляет независимыми подпотоками внутри домена симуляции через смещение `stream_offset` относительно базового индекса `base_stream_idx`.
- Выполняет строгую валидацию входных параметров и типов (запрет `bool`, `bound >= 0`, `variance >= 0`).

**Не делает:**
- **Не считывает данные из файлов.** Механика предзаписанных трасс (`DataStream`) исключена из модуля для проектирования в рамках отдельной будущей фичи `FEAT-RNG-003`.
- Не рассчитывает физику движения абонентов, состояние радиоканала и сетевой трафик (это задача соответствующих моделей, которым генератор передаётся через Dependency Injection).
- Не управляет глобальной раздачей `base_stream_idx` для подсистем (это зона ответственности `SimulationManager`).

## 3. Входы, выходы и зависимости

| Вход | Откуда | Формат / смысл |
|---|---|---|
| `seed` | Вызывающий модуль / ядро | `int` (по умолчанию `12345`; `0` заменяется на `12345`) — начальное зерно генератора. Запрещены отрицательные числа и `bool`. |
| `base_stream_idx` | Вызывающий модуль / ядро | `int` ( $\ge 0$ ) — базовый индекс потока подсистемы для изоляции коллизий. |
| `stream_offset` | Модели симулятора | `int` ( $\ge 0$ ) — смещение подпотока (чаще всего равно `UE_ID`). |
| `run_idx` | Вызывающий модуль / ядро | `int` ( $\ge 1$ ) — номер независимого прогона симуляции. |
| `engine` | Вызывающий модуль / ядро | `str` (`'MRG32k3a'`, `'Philox'`) — выбор математической стратегии. |
| Параметры распределений | Модели симулятора | `min_val`, `max_val`, `mean`, `variance`, `bound` (строгая валидация границ `float`/`int`). |

| Выход | Куда | Формат / смысл |
|---|---|---|
| Базовое число $U(0, 1)$ | `RandomGenerator` | `float` строго в диапазоне $[0.0, 1.0)$ из методов `rand_u01()`. |
| Случайная величина | Модели симулятора | `float` (`uniform`, `normal`, `exponential`) или `int` (`get_integer`). |

**Зависимости:**
- Только встроенная библиотека Python 3.12 (`math`, `typing`). Внешних зависимостей от других модулей проекта нет.

> **Соглашение по стилю докстрингов (`optional`)**  
> Запись вида `param (float, optional)` в докстрингах означает только то, что параметр имеет значение по умолчанию (например, `0.0`), и его можно не передавать при вызове. Это **не означает**, что параметр принимает тип `None`. Сигнатуры методов не используют `typing.Optional`.

## 4. Как проверить работу

Модуль запускается и верифицируется автономно локальными модульными тестами (17 проверок) из корня проекта:

```bash
pytest test_rng.py -v
```

Тесты проверяют совпадение `MRG32k3a` с эталоном `ns-3`, математические границы `Philox4x64`, отсутствие коллизий между `stream_offset`, равномерность `get_integer` на отрицательных границах и выбросы исключений `ValueError`.

## 5. Основные компоненты

| Компонент / Файл `RNG.py` | Назначение | Где используется |
|---|---|---|
| `UniformEngine` (`Protocol`) | Статический контракт ядра генерации ПСЧ с методом `rand_u01()`. | Для проверки соответствия стратегий внутри `RandomGenerator`. |
| `RandomProvider` (`Protocol`) | Статический контракт источника распределений (4 метода). | Как аннотация типа в моделях `Mobility`, `Channel`, `Traffic` (DI). |
| `RngStream` | Стратегия `MRG32k3a` с предвычислением матриц перехода для сдвига по потокам и прогонам. | В `RandomGenerator` (по умолчанию `engine='MRG32k3a'`). |
| `PhiloxStream` | Стратегия `Philox4x64` (10 раундов, буфер на 4 числа, нормализация IEEE-754 мантиссы). | В `RandomGenerator` при `engine='Philox'`. |
| `RandomGenerator` | Фасад генерации случайных величин. Управляет словарём кэшированных потоков `_streams` по стратегии `_ENGINES`. | Единая точка конфигурации в `SimulationManager` и внедрения в модели. |

## 6. Один типичный сценарий

**Сценарий: Получение нормальных величин через ленивую инициализацию потока**
1. Ядро симулятора создаёт `rng = RandomGenerator(seed=12345, base_stream_idx=1000, run_idx=1, engine='MRG32k3a')` и внедряет этот объект в `MobilityModel`.
2. Модель вызывает `rng.normal(mean=0.0, variance=1.0, bound=3.0, stream_offset=1)`.
3. Внутренний метод `_get_stream(1)` проверяет словарь `_streams`. Так как потока ещё нет, он инициализирует `RngStream(seed=12345, stream_idx=1001, run_idx=1)` и сохраняет его в `self._streams[1]`.
4. Метод `normal()` запрашивает два базовых числа через `rand_u01()`, вычисляет пару величин по методу Бокса — Мюллера, сохраняет вторую величину в `self._normal_cache[1]` и возвращает первую (с учётом проверки `bound`).
5. При следующем вызове для `stream_offset=1` второе число мгновенно извлекается из `_normal_cache[1]`.
